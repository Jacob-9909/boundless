# Astryx in Boundless

Boundless renders its UI with [Astryx](https://github.com/meta/astryx) (`@astryxdesign/core`, Meta's
open source design system) and a custom Boundless theme. This page is the working guide for code in
`src/`.

## How it is wired

| Piece | Where | Notes |
| --- | --- | --- |
| Cascade layers | `src/app/globals.css` (first line) | `reset, theme, base, astryx-base, astryx-theme, culture, components, utilities`. `globals.css` must stay the first import in `src/app/layout.tsx`. |
| Theme source | `src/themes/boundless/boundlessTheme.ts` | `defineTheme({ extends: neutralTheme })`: type, radius, control sizes, component overrides. |
| Built theme | `src/themes/boundless/boundless.{css,js}` | Generated. After editing the source run `npx astryx theme build src/themes/boundless/boundlessTheme.ts`. |
| Theme module | `src/astryx-themes.ts` | Generated by `npx astryx theme add boundless`. Do not edit. |
| Provider | `src/app/providers.tsx` | `<Theme mode="light">` + `LinkProvider` (Next.js `Link` for every Astryx `href`). |
| Culture colors | `globals.css`, `@layer culture` | Maps `--c-primary/ink/paper...` to Astryx tokens (`--color-accent`, `--color-text-primary`...). Any element that sets `themeVars(culture)` must also carry the `culture` class, or nested Astryx components keep the root colors. |
| Shell | `src/app/(app)/layout.tsx` | `AppShell` + `TopNav` + `AppSideNav` (`src/components/SideNav.tsx`) + our `BottomNav` on phones. AppShell renders the skip link and `<main>`; pages must not add their own. |
| Form fields | `src/components/fields.tsx` | `TextField`, `TextAreaField`, `SelectField`: uncontrolled wrappers (`name`, `defaultValue`) so Astryx inputs post to server actions like a plain `<input name>`. |
| Icons | `src/components/Icon.tsx` | `<Icon name>` for elements (`icon={<Icon name="plus" size={18} />}`); `svgIcon(name)` returns an SVG component for props typed `IconType` (client code only). |

The Tailwind bridge (`tailwind-theme.css`) is not loaded: this app already uses `text-primary`,
`rounded-lg` and `shadow-md` with its own meaning. For a hand-built surface, reach the Astryx tokens
through arbitrary values: `bg-[var(--color-background-card)]`, `border-[var(--color-border)]`,
`rounded-[var(--radius-container)]`, `text-[var(--color-text-secondary)]`.

Look up any component with `npx astryx component <Name>` (props, examples, theming targets).

## Mapping from the old class strings

| Old (`src/components/ui.tsx`) | Astryx |
| --- | --- |
| `<Link className={btn}>` | `<Button href="/x" label={t("...")} variant="primary" size="lg" />` |
| `<button className={btn}>` in a `<form action>` | `<Button type="submit" label={...} variant="primary" size="lg" />` (`isLoading` while pending) |
| `btnGhost` | `variant="secondary"`; quiet text actions `variant="ghost"` |
| destructive (delete, block) | `variant="destructive"` |
| icon-only round buttons | `<IconButton label={...} icon={<Icon name="..." />} />` |
| `<input className={field}>` + `<label className={labelCls}>` | `<TextField name label ... />` (server forms) or `<TextInput value onChange label />` (client state) |
| `<textarea>` | `TextAreaField` / `TextArea` |
| `<select>` | `SelectField` / `Selector` with `options` |
| checkbox / switch / radio | `CheckboxInput`, `Switch`, `RadioList` |
| `card` wrapper | `<Card>` (`padding={0}` for lists split by hairlines) |
| `tag` span | `<Badge variant="success \| warning \| error \| info \| neutral \| <hue>" label={...} icon={...} />` |
| `pill` toggle chips | `ToggleButton` (client state) or `Token` with `href` (links) |
| `Notice` | still `Notice` from `ui.tsx` (now Astryx `EmptyState` / `Banner`) |
| status messages | `<Banner status="info \| success \| warning \| error" title description />` |
| dialogs, confirm | `Dialog` / `AlertDialog` |
| tooltips | `Tooltip` |

Keep the Boundless identity pieces from `ui.tsx` as they are: `Logo`, `Flag`, `Landmark`, `Avatar`
(culture pattern + flag), `LevelBadge`, `BoardBadge`, `TagText`, `NationalityChip`, `StationLabel`,
`PageHead`, `PostCard`. They already sit on the Astryx tokens.

## Rules

- Server components may render Astryx components and pass elements (`icon={<Icon ... />}`), strings and
  numbers. Functions (`onChange`, `svgIcon(...)`) only from client components.
- Touch targets: interactive controls stay at least 44px tall on phones. The theme sets
  `--size-element-*` to 32/40/44px (36/44/48px on touch screens); use `size="lg"` for page-level CTAs.
- Do not hard-code hex colors for UI chrome; use culture classes (`bg-primary`, `text-ink`, `bg-soft`)
  or Astryx tokens. Board colors and flag art stay as they are.
- Every `t("한국어")` key needs an English line in `src/lib/en.ts` (`npm run i18n`).
